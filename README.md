# 4F4F-4AJB | SMART Recovery Support Web App

An open-source, local-first web app built to break the hesitation of taking the first step in recovery. Inspired by my son **Ajaib**—my ultimate motivation—and dedicated to the Australian AOD workers (**MITA, Nick, Caraniche, Sarah**) who help us find hope in our darkest hours. Total self-honesty, local-first data.

## 🌟 Key Features
- **Admin Bypass Panel:** An administrative interface to instantly change modules, jump anywhere in the app, or override system paths.
- **Main User Path:** A progressive, step-by-step interactive journey tracking the core principles from the very first tool to the last.
- **Self-Checker & Rewards:** A milestone system where users evaluate their own progress. When you achieve a goal, you give a reward to yourself to move forward.
- **Local-First Privacy:** No cloud databases or servers. All data remains 100% private on your own device.

## 🛠️ How to Use
1. Open the web app on any smartphone or computer browser.
2. Work through the tools sequentially or use the Admin panel to test specific features.
